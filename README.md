# ✈️ Aircraft Airfoil Noise Prediction Using Machine Learning

An interactive Machine Learning web dashboard application that predicts acoustic self-noise footprints (sound pressure level in decibels) generated by structural aircraft airfoil components. The calculations leverage an optimized **XGBoost Regressor** trained on empirical NASA wind tunnel matrices.

## 📊 Performance & Specifications
* **Core Machine Learning Framework:** XGBoost (Extreme Gradient Boosting Ensemble)
* **Dataset Engine:** NASA Airfoil Self-Noise Dataset (1,503 experimental test conditions)
* **Model Accuracy Benchmark:** **~94.8% R² Score** on holdout evaluation vector splits.
* **UI Design Blueprint:** Premium Dark Theme custom SaaS interface design injected viaScoped CSS styling blocks.
